# Agentic Layout for Interactive-Project-Management-Tool
The aim of this repo is to upload and access all the learning and supporting materials needed to create a Final AGENTS.md file necessary for building the.  Gantt Application

# Examples of some of the contents

Summary.md of the code base

Clarifications.md file for the certain clarifications reached while understanding the code repo and if additional packages to be installed or not to work on this code repo

Plan.md: With the help of Summary.md and Clarifications.md and visual prompting,  layout the step by step implementation tasks for the development of the additional features of the already present application. Incorporate the UML diagrams that lays out the highlevel schematic architechture of the the complete application and how each of the component interacts with eachother. 

AGENTS.md: The final instruction file for the agent to develop the feature step by step following SDLC playbook and output the app ready to be shipped. 

# Additional files: 
1.Software_featureDeveloperAGENTS.md: Who would develop the file. 

2.TestAgent.md: instructions on how to robustly test the feature and the application at all SDLC steps. 

3.ApplicationSecurityAGENT.md: To review the plan and code generated by the Software_featureDeveloperAGENT from cybersecurity perspective
